## Substitutions and decisions taken without asking

1. **DE filename convention.** `.claude/CLAUDE.md` 6.11 asks for native
   filenames under non-English locales. The DE route resolves its URL through
   `insightEnToDe`, so the German URL is native while the file id stays
   English. Following the collection's existing shape was chosen over renaming
   a convention that spans 78 files. The live URL is fully German, which is
   what the rule is protecting.
2. **FR title and slug do not match word for word.** The slug was drafted
   before the deep-translate passes; pass 1 then re-authored the title. Both
   are native French and the slug still carries the query ("allbirds en
   chine"), so the slug was left alone rather than renamed after the fact.
3. **Euro placement inside quoted filings.** Beside the filed dollar figure,
   not instead of it. Replacing a number inside a quotation would misquote the
   filing.
4. **`public/llms-full.txt` committed.** It is a build output the repo tracks,
   and leaving it dirty after a publish would make the next run look like it
   had uncommitted work.
